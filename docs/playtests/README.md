# Протокол плейтеста

1. Ссылка на сборку, наушники, ничего не объяснять.
2. Молча наблюдать 10 минут, засекать: первый шаг, первый хлопок, первая победа, первая смерть, причина.
3. После игры спросить:
   - Объясни своими словами, что это за игра.
   - Когда ты испугался? Что произошло?
   - Почему ты умер в последний раз? Это было честно?
   - Где было скучно?
   - Сыграешь ещё? (засчитываем, только если тестер сам начал новый забег до вопроса)
   - Показал бы другу? Что именно?
4. Отчёт — файл `YYYY-MM-DD.md` в формате «наблюдение → гипотеза → изменение → результат».

**Пороги** (из `01-concept.md`): ≥ 70% сами начинают новый забег; сессия ≥ 20 мин; ≥ 80% объясняют игру одной фразой; ≥ 70% считают смерть честной.
