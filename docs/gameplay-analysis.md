# Анализ геймплея ЭХО и план улучшений

> 2026-10-09. Основа: симуляция ботом (`npm run sim`, 300 забегов на глубину), замер влияния улучшений, ревью кода и дизайна. Плейтестов с людьми ещё не было: выводы о «весело / не весело» — гипотезы.

## Что работает

1. **Ядро «видеть = быть услышанным»** даёт решение на каждой секунде: каждое действие имеет цену в метрах слышимости.
2. **Охотник идёт на звук, а не на игрока.** Это даёт понятную контригру: отойти, замереть, бросить камень.
3. **Слухач с ритмом** учит другому темпу: рядом с ним нельзя идти, можно только красться.
4. **Читаемость:** цвет никогда не врёт (красный = монстр), у монстров свой силуэт и дрожь, звук пространственный.

## Проблемы (найдены данными)

| # | Проблема | Данные | Статус |
|---|---|---|---|
| 1 | Плато сложности после глубины 4 | побег 56 → 56 → 41 → 44% (гл. 4, 5, 6, 8) | **исправлено**: с глубины 5 монстры слышат дальше (+6%/глубина) и быстрее бегут; теперь 58 → 52 → 41 → 34% |
| 2 | Не было способа убежать: охотник (3,4 м/с) быстрее ходьбы (3,2) | — | **исправлено**: спринт 5,2 м/с с ценой (шумно, выносливость, одышка) |
| 3 | Смерть отбрасывала к глубине 1 — длинный забег наказывался полностью | — | **исправлено**: зелёный маяк каждые 5 глубин |
| 4 | 7 из 10 улучшений не влияют на исход бота | база 59%; тихие +5…+7, остальные 0 | частично: бот не умеет «видеть», визуальные улучшения он не оценит. Нужен плейтест (см. ниже) |

## Предложения (по ценности / стоимости)

| Идея | Зачем | Цена | Приоритет |
|---|---|---|---|
| **Повтор смерти сверху (3 с)** | игрок видит, откуда пришёл монстр → смерть честная → «ещё раз» | средняя | высокий |
| **Монстр «Тень»: слышит тишину** — идёт к игроку, который стоит дольше 4 с | ломает доминирующую стратегию «замри и жди» | низкая (1 состояние ИИ + данные) | высокий |
| **Громкие поверхности** (вода, стекло, решётки): шаг в 2 раза громче | маршрут = решение, а не просто путь к выходу | средняя | высокий |
| **Ребаланс улучшений:** «Двойное эхо» → вторая волна раскрывает монстров за стенами; «Красная память» → монстры видны через стены 1 с после хлопка; «Быстрые руки» → +1 камень на глубину | у каждого улучшения есть механический эффект, а не только визуальный | низкая | высокий |
| **Испытания и ежедневный рекорд** («ни одного хлопка», «только камни») | повод вернуться, сравнение с друзьями | низкая | средний |
| **Опциональный микрофон**: реальный шум игрока = звук в игре | клипы стримеров (см. `01-concept.md`) | низкая | средний |
| **Реверберация по размеру комнаты** | звук сообщает форму пространства | низкая | средний |
| **Бот с навигацией по хлопкам** | балансировать улучшения данными | средняя | средний |
| **Стая** (3 мелких монстра, переговариваются щелчками) | новый тип угрозы для глубин 10+ | средняя | низкий |

## Что проверить на первом плейтесте

1. Понимают ли игроки без подсказки, что охотник идёт к звуку, а не к ним? (вопрос после первой смерти)
2. Используют ли бег как побег или как способ быстрее дойти до выхода? Если второе — нужна более высокая цена.
3. Пугает ли скример на 3-й смерти или уже раздражает? (если раздражает — показывать с вероятностью 1/3)
4. Сколько глубин проходят до первого зелёного маяка? Если меньше 3 у большинства — маяк каждые 3 глубины.
