# Производительность

| Метрика | Бюджет | Замер 0.2 | Как мерили |
|---|---|---|---|
| Логика (sim) | ≤ 4 мс | **0,4–1,1 мс** на кадр | `loop.simMs`, смоук-тест `performance` (глубина 6, 4 хлопка подряд) |
| Начальный бандл | < 1,5 МБ gzip | **≈ 153 КБ gzip** (three 117 + игра 33 + css 2) | `vite build` |
| Кадр | 16,6 мс | **не измерено на GPU** | см. ниже |
| Отрисовки | под контролем | 1 на облако точек + 1 на окклюдер + проходы постобработки | `renderer.info` в оверлее F1 |
| Аллокации в цикле | 0 | облако точек и симуляция без аллокаций; звук создаёт узлы Web Audio на каждый звук (норма для Web Audio) | ревью кода |

**Честно о кадре.** В облачной среде нет GPU: Chromium рисует через программный SwiftShader, там кадр 200 мс (p50) / 370 мс (p95) при 1280×720. Это не показатель реального железа. Первый замер на настоящей встроенной графике (Intel UHD / Steam Deck) запланирован на день 11 (`plan-2-weeks.md`): открыть `?debug`, F1, сделать 4 хлопка, записать FPS и число точек сюда.

Рычаги, если не хватит: число лучей хлопка (560) и точек на стену (6) в `src/render/echo.ts`, `pixelRatio` (сейчас ≤ 1,5), разрешение bloom (половина экрана).
