# ADR 0001 — стек и архитектура

**Контекст.** Один человек + ИИ, веб сначала, потом Steam (Tauri). Нужна 3D-сцена от первого лица из облака точек, процедурный звук, детерминизм для тестов и ежедневных сидов.

**Варианты.** PixiJS 8 (2D) — вид сверху повторяет Dark Echo, отказ. Babylon.js — тяжелее, без выигрыша. Three.js — лёгкий, точки и постобработка из коробки.

**Решение.**
- TypeScript strict + Vite + **Three.js 0.180** (`Points` + свой `ShaderMaterial`, `EffectComposer`: RenderPass → UnrealBloom → свой финальный шейдер → OutputPass).
- Web Audio API без библиотек (HRTF `PannerNode`, `ConvolverNode` с процедурным импульсом, `DynamicsCompressor` как лимитер).
- Логика игры — **2D-сетка** (x, y в метрах), чистые функции в `src/game` без DOM/WebGL/звука. Рендер переводит y в ось Z.
- Фиксированный шаг 60 Гц, RNG sfc32 с сидом (`?seed=`), шина событий: симуляция кладёт события в `world.events`, приложение публикует их в `EventBus`, звук/рендер/UI подписываются.
- Контент — данные: `src/content/{monsters,depths,upgrades}.ts`. Баланс — `src/game/config.ts` с единицами.

**Последствия.** Безголовый бот гоняет сотни забегов за секунды (`npm run sim`). Детерминизм проверяется хешем состояния. Вертикальных уровней (лестниц, мостов) нет — это осознанное ограничение 2D-сетки; при необходимости — слои сетки.
