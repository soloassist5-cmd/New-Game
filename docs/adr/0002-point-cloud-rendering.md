# ADR 0002 — рендер облака точек

**Контекст.** Мир состоит только из точек, оставленных звуковыми волнами. Хлопок даёт ~10–15 тыс. точек, они живут 2–8 с. Нужны 60 FPS на встроенной графике и никаких аллокаций в кадре.

**Решение.**
- Один `THREE.Points` на 220 тыс. точек, **кольцевой буфер**. Точки не удаляются: время рождения и жизнь хранятся в атрибутах, затухание считает вершинный шейдер. Старые точки перезаписываются.
- В GPU каждый кадр уходит только «грязный» диапазон (`addUpdateRange`); при переходе через конец буфера — два диапазона.
- Отложенное рождение (`birth = now + distance / waveSpeed`) даёт видимый фронт волны без логики на CPU.
- **Окклюзия:** невидимая сетка граней стен (`colorWrite: false`) пишет глубину, точки на стенах сдвинуты на 3 см к наблюдателю. Точки за стенами не просвечивают.
- Аддитивное смешивание, `depthWrite: false`, одна отрисовка (draw call) на всё облако.

**Отвергнуто.** Отдельный меш на каждую волну (много отрисовок и аллокаций). Расчёт затухания на CPU (каждый кадр 220 тыс. записей).

**Последствия.** Стоимость — заливка пикселей, а не вершины. Размер точек ограничен 7 px (монстры и выход — 14 px). Если встроенная графика не потянет — уменьшить число лучей хлопка (`RECIPES` в `src/render/echo.ts`) и разрешение bloom.
